# Скриншоты Vacancy Agent

Все изображения визуально проверены перед подготовкой публичной копии.
Это исторические кадры исходного проекта, не результат запуска текущей публичной версии.

- 01–03: описание проекта и архитектуры на раннем этапе.
- 04: исторический прогон 604 тестов; актуальные результаты указаны в README.
- 05: итоговый счётчик прогона поиска (400 получено, 1 уведомление).
- 06: карточки публичных вакансий и кнопки решения пользователя в Telegram.
- 07: локальный API успешно запущен; адрес loopback.

На изображениях нет токенов, chat_id или контактов кандидата. На кадре 04 видны имя пользователя и имя компьютера автора; приватные пути и секреты отсутствуют.
